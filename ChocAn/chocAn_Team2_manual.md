## How to Clone and Create JAR
The first step to being able to run Team 2’s ChocAn system is to clone the project in Bitbucket. Go into the Fall2022Team2 repository and click “Clone” in the top right corner. Copy the link to the repository and then go into your desired app to run the project. For this manual, we will be describing how to use the project in Eclipse. In Eclipse, click File > Import, “Projects from Git” > Next.  Clone URI > Next. Copy and paste the URI for the repo into the URI field and enter your Bitbucket username and app password > Next. For reference, the URI for the Team2 repo is https://klandrzejewski@bitbucket.org/tklocklear/fall2022team2.git . No change > Next. If wanted, set a directory for the repo > Next. Import existing Eclipse projects > Next. Select the project that appears > Finish. Now the project is imported to the remote Git repo. 

Under the “Working Tree” in the repo, navigate to the src folder, and the src folder inside of that. Within that is a project folder titled chocAn which holds the java class documents. To generate the JAR, right click on the project name > Export. Under Launch Configuration, select Driver – ChocAn, and the export destination to however you will access it on your desktop, such as C:\Users\yourusername\Desktop\ChocAn.jar. An executable JAR file will then be created on your desktop. You can run via a command prompt or terminal to run the program such as “jarFolder>java – jar ChocAn.jar”.

Additionally, to access the JavaDocs, go to the "doc" folder in the repo and click on index.html.


## How to Run with GUI

In order to access the full functionality of the program using the GUI, open the Interface.java document and run. This is the login window for the program and where everything will begin. There is 1 user programmed for each type of user, Provider, Operator, Manager, and Weekly Timer. To access the Provider Menu, the username is “trina” and the password is “1234”. To access the Manager Menu, the username is “mscott” and the password is “1234”. To access the Operator Menu, the username is “rsmith” and the password is “1234”. To access the Weekly Timer Menu, the username is “timer” and the password is “1234”. 

To use the Provider’s Menu, type “trina” into the username slot of the welcome menu and “1234” into the password, then click “Log In”. You will then be taken to the Provider Menu. While there, the first step is to validate the member using their member ID. There are 3 members created into the system, with their number IDs being “1320”, “5892”, and “4931”, with all three members having set their status to valid. In order to validate the member, type their member ID in the text input box under “Member #” and click on “Validate Member”. The validation status of the member will then be displayed underneath the text input. If they are a valid member, it will show up as “Valid” and the provider can continue with their services, otherwise "Unfound" means it was an incorrect member number, or any other word is a reason for a non-valid member. To see the service codes, click on the “Request Provider Directory” button which will bring up a menu of the given service codes, their service names, and fees. To return back to the Provider Menu, click on the “Return to Menu” button on the bottom left. The Bill ChocAn action assumes that you have already validated the member. Once again, validate your member as previously mentioned, then fill out all of the other input boxes with their needed information, including the member ID in order to properly bill the correct member. When all boxes are filled, click the “Bill ChocAn” button and the fee for that service will be displayed, demonstrating that the billing was successful. If the service code is incorrect, the billing will not be completed and a message informing of the incorrect service code. In this case, try again with the correct service code. To exit out of the system, hit the “Exit” button in the bottom left corner. This will bring you to the exit screen and you can return to the welcome/log in screen once again using the button in the middle of the screen.

To use the Operator’s Menu, type “rsmith” into the username slot of the welcome menu and “1234” into the password, then click “Log In”. You will then be taken to the Operator Menu. Type into the text input box which action you wish to complete, 1 is Add, 2 is Delete, and 3 is Edit. Once your option is typed into the box, hit either “Update Member” or “Update Provider” based on your desired action. Both actions will take you to the same screen and the process is the same. If you are adding a member or provider, ensure that all boxes are filled out besides the editing box (and validation if you are updating provider). For editing, fill out the box that you wish to edit, the ID # and then type that number choice into the editing box. There are 3 provider numbers in the system and they are the same as the member id numbers for simplicity, but are known to be different due to a different storing system for members/providers. These numbers once again are “1320”, “5892”, and “4931”. For delete, simply input the ID number you wish to delete. When you are completed, click the “Edit” button and you will be returned to the Operator Menu with a message saying that the update was successful. If the record you are trying to update cannot be found, you will receive an error message instead. To exit out of the system, hit the “Exit” button in the bottom left corner. This will bring you to the exit screen and you can return to the welcome/log in screen once again using the button in the middle of the screen.

To use the Manager’s Menu, type “mscott” into the username slot of the welcome menu and “1234” into the password, then click “Log In”. You will then be taken to the Manager Menu. Type in the number of which report you would like to generate, the numberID of the provider (if you are generating a provider report) or member (if you are generating a member report), and then click “Confirm Answer”. The member number "1320" is fully able to be generated and the provider number "4931" can be fully generated, otherwise it will error due to the records not being fully created. You will then be shown the report you wanted in the reports folder in the repo. Check that the report you wanted is the correct date. Click the “Return to Menu” button to return to the Manager’s Menu. To exit out of the system, hit the “Exit” button in the bottom left corner. This will bring you to the exit screen and you can return to the welcome/log in screen once again using the button in the middle of the screen.

To use the Weekly Timer’s Menu, , type “timer” into the username slot of the welcome menu and “1234” into the password, then click “Log In”. You will then be taken to the Weekly Timer Menu. Click on the “Run Main Accounting Procedure” button to run the main accounting procedure. A message titled “Success” will be displayed once the procedure has been successfully completed. . To exit out of the system, hit the “Exit” button in the bottom left corner. This will bring you to the exit screen and you can return to the welcome/log in screen once again using the button in the middle of the screen.

These are all the functionalities of the ChocAn system that can be tested using the GUI. 



## How to Test

In order to test the functionality of the tests, go into each test case found in the test folder in the Fall2022Team2 repo. There is a test file for each team member and in there you can click the run button in Eclipse and run the respective tests, or using the JAR with a command line to those tests. Tests will be shown as successful with a green pass line being shown. The ANT script is the build.xml located in the repo, with it building a JAR in the release folder that can be used to run the program.
